**Team:** NURLANKYZY ZHANSHUAK | SRAZHDIN YASMIN | URINBAY NURGUL

## Features implemented (Assignment 5)

### DOM Manipulation & Styling
- Day / Night theme toggle (with localStorage)
- Dynamic content updates (greetings, ratings, product list)
- Star rating system (click to rate)
- Read More / Read Less toggle
- Dynamic style changes (background color, theme colors)

### Event Handling
- Button click listeners (theme, filters, rating, forms, popup)
- Keyboard navigation (Arrow Left / Right for navbar links)
- Escape key closes popup
- Form submit handlers with preventDefault

### Callbacks & Switch
- Contact form async submission with success callback
- Switch statement for time-of-day greeting
- Switch for product filter categories

### Advanced JS
- Objects with methods (`getFormattedPrice`)
- Arrays of products
- Higher-order functions: `filter()`, `map()`, `forEach()`
- Sound effects via Web Audio API
- Animations (scale on stars, transitions on theme & cards)

### Validation (strengthened)
- `trim()` on all text inputs
- Rejects whitespace-only names
- Minimum length checks
- Password: min 8 characters + at least one digit
- Live validation feedback

### Structure
- HTML / CSS / JS fully separated
- Clean, commented code
- Shared `js/script.js` used on all pages

## How to run
Open `index.html` in a browser (or deploy via GitHub Pages / Netlify).

## Deploy
Push to GitHub and enable GitHub Pages, or drag the folder to Netlify.
