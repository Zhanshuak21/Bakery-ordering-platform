# Sweet Crumb Bakery

A responsive multi-page website for a fictional bakery, created as a midterm project for the Front-End Development course.

**Live Demo:** `https://zhanshuak21.github.io/Bakery-ordering-platform/`

## Pages

- **Home** (`index.html`) — Hero section, image carousel, feature cards
- **Menu** (`menu.html`) — Product cards and price table
- **About** (`about.html`) — Bakery story, values, process
- **Gallery** (`gallery.html`) — Image carousel and product cards
- **Order** (`order.html`) — Order form with product selection
- **Contact** (`contact.html`) — Contact information and message form

---

## Technologies Used

- HTML5
- CSS3 (custom styles + Flexbox)
- Bootstrap 5.3 (Grid, Navbar, Carousel, Cards, Forms, Buttons)
- Responsive design (Mobile / Tablet / Desktop)

---

## Features

- Fully responsive layout
- Bootstrap navigation bar with mobile hamburger menu
- Image carousels (9 slides)
- Styled product and contact cards
- Working order and contact forms
- Consistent design and color palette across all pages
- Team member information on relevant pages
